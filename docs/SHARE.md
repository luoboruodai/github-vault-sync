## English

**Short description**

> Preview-first Obsidian desktop vault sync through your own private GitHub repository. Review conflicts, confirm each upload, and optionally back up sensitive plugin settings in encrypted form.

**Shareable introduction**

> GitHub Vault Sync helps you keep an Obsidian desktop vault across devices using local Git, Git LFS, and a separate private GitHub repository. See local and remote changes before syncing, choose how conflicts are handled, and confirm the result yourself—periodic checks do not upload in the background. v0.2.0 also offers optional media optimization advice and encrypted settings backup. Download the manually installable ZIP, not GitHub's automatic source archive. Windows and macOS are supported; native Windows Obsidian GUI acceptance is still pending.
